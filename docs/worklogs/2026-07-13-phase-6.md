## Decisions and remaining risks

- `GaugeLinkTensor` and `TaGaugeField` own typed compact host storage. Erased
  values are restricted to explicit fixture/extension conversions.
- Host extensions reuse the same prepared action/gradient leaves as direct
  APIs. The periodic fixed-size stencil remains custom because tenferro has no
  equivalent periodic gather primitive.
- Symbolic graph metadata cannot prove equality between independently keyed
  `TensorAxis` dimensions. Known contradictory constants fail during graph
  construction; executor binding checks and complete host-reference equality
  checks reject concrete mismatches without panicking. This upstream limitation
  is tracked by [tenferro-rs #1370](https://github.com/tensor4all/tenferro-rs/issues/1370).
- Phase 7 must add role-split rules before claiming autodiff support.
