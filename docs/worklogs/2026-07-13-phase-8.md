# Phase 8 SU(3) evolution work log

## Scope and reference

Implemented only SU(3) exponentiation, normalization, eager link evolution,
and crate-private HMC sanity support. The Julia oracle is Gaugefields.jl commit
`9e5719970770f4497405a856315c90bef7f74449`: `exptU!` lines 603--806,
`normalize_U!` lines 2387--2454, and the no-wing HMC update convention. No
public sampler, integrator framework, RNG policy, GPU fallback, or eigensolver
was introduced.

## Numerical kernels

- `exp_ta` uses the Julia Cardano eigenvalues, explicit eigenvectors, and the
  fourth-order fallback when the eigenvector norm squared is below `1e-24`.
  The fixture contains zero, two regular random cases, an exact degeneracy, and
  cases immediately below and above the reference branch threshold.
- Review added balanced nonzero coefficient cases whose scalar sum is zero.
  Pinned `exptU!` contains the same erroneous `csum == 0` identity shortcut, so
  these generator cases deliberately use pinned Julia `exp_T4` for its fallback
  or `LinearAlgebra.exp` after the identical Gell-Mann construction. The old
  Rust shortcut failed the oracle by `0.6496369390800625`; the corrected check
  requires every scaled coefficient to be zero. A field-update regression
  proves the balanced momentum propagates beyond the site-local kernel.
- Quality review added finite-range overflow tests. `t=f64::MAX` with a maximum
  finite coefficient overflows the scaled vector; a `sqrt(f64::MAX)`-scale
  coefficient remains finite after scaling but overflows Cardano invariants.
  Both now return `Su3NumericalRange`, distinct from nonfinite input. Staged
  checks also guard the generator, Cardano denominator/eigenvalues,
  eigenvectors, fourth-order fallback, and final assembly. No clamping or
  out-of-scope scaling-and-squaring path was added. A huge-momentum field test
  verifies all four links remain bitwise unchanged before packing/contraction.
- The immediately-above-threshold Julia result has an inherent unitarity
  residual of `3.3643510607417326e-6`; Rust matches its elements, so strict
  invariants apply to regular analytic inputs while this oracle case uses the
  measured reference-relative bound.
- `normalize_su3` performs row Gram--Schmidt and a conjugated cross product,
  rejects row norms at or below `1e-30`, and commits only after success.
  A pinned `normalize_U!` oracle now normalizes identity, deterministic random
  SU(3) perturbation, and controlled drift through a `1^4` no-wing field.
  Dedicated failures cover a zero first row, a linearly dependent second row,
  NaN, and infinity, with exact typed rows and bitwise no-partial-mutation.

## Evolution ownership and layout

`CpuEvolutionContext` privately owns `CpuBackend` and its associated bounded
default runtime cache. `exp_ta_update` packs `[3,3,NX,NY,NZ,NT]` exponentials,
then enters one cached backend session. Each direction uses stable slot `mu`,
contracting lhs axis 1 with rhs axis 0 and batching axes 2--5. All four outputs
are converted and validated before replacing `GaugeLinks`; injected failures at
each direction leave every complex component bitwise unchanged.

The cache object and slots are reused across identical shapes. Cache entry
counts are provider-dependent: tenferro revision `51bc0a7` sends unconjugated
cpu-faer dot-general directly to the strided backend, bypassing GEMM analysis,
so its valid steady-state `CacheStats` is zero entries. Tests require stable
stats and verify `clear_cache`, not a false nonzero-entry promise.

## HMC regression

The test-only `4^4` driver uses ChaCha8 fixed seeds, symmetric
`U(dt/2) -> P(dt) -> U(dt/2)`, `P=(i/2) sum p_a lambda_a`,
`K=(1/2) sum p_a^2`, and `P <- P - dt*force/NC`. The final deterministic run
reported link/momentum reversibility `1.46e-13`/`2.29e-14`, unitarity/determinant
drift `3.30e-13`/`6.44e-15`, energy errors `5.828e-3`, `1.456e-3`, and
`3.638e-4` as `dt` halved, ratios `4.004` and `4.001`, and acceptance `6/6`.

The final optimized three-update scaling diagnostic reported `6060.0`,
`3423.9`, and `3883.9 ns/site-step` for `2^4`, `4^4`, and `8^4` lattices respectively.
The tiny case is overhead dominated; the two larger volumes show the expected
approximately linear packing-plus-contraction cost.

## Verification

The final verification gate regenerated the Julia fixtures byte-stably and ran
formatting, clippy with all targets/features, no-default and all-feature
workspace tests, doctests, rustdoc, the release ignored scaling diagnostic, and
`git diff --check`; all completed successfully. The host's parallel `rust-lld`
