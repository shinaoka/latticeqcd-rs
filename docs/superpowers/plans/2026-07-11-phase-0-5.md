# Gaugefields-rs Phase 0–5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete GitHub issues #2–#7, producing a tested CPU-only SU(3) gauge-field library through Wilson action forces.

**Architecture:** A single `gaugefields` crate wraps validated tenferro tensors while keeping site-local SU(3) arithmetic in an internal fixed-size `Mat3`. Periodic indexing feeds allocation-free eager observables and force kernels. All tenferro Git dependencies use one exact `origin/main` revision.

**Tech Stack:** Rust 2024, tenferro-rs at rev `f504ba0a8668baca89ab1d4348b9475ff85377b4`, `num-complex`, `thiserror`, `npyz`, `serde`, `serde_json`, Julia/Gaugefields.jl fixtures, GitHub Actions.

---

## File map

- `Cargo.toml`: standalone workspace and shared dependency pins.
- `gaugefields/Cargo.toml`: crate features and dependencies.
- `gaugefields/src/lib.rs`: deliberate public exports only.
- `gaugefields/src/error.rs`: typed validation and fixture errors.
- `gaugefields/src/field.rs`: lattice, link, collection, cold-field, and force payload types.
- `gaugefields/src/fixture.rs`: NPY/JSON fixture parsing.
- `gaugefields/src/mat3.rs`: all fixed-size site-local complex matrix arithmetic.
- `gaugefields/src/index.rs`: site/coordinate/neighbor mapping and link block access.
- `gaugefields/src/observables.rs`: plaquette, measurement staple, and Wilson action.
- `gaugefields/src/force.rs`: `dsdu`, TA gauge force, and dense action gradient.
- `gaugefields/tests/*.rs`: public integration and fixture parity tests.
- `fixtures/generate.jl`: authoritative Julia fixture generator.
- `fixtures/*.npy`, `fixtures/*.json`: small checked-in parity data with provenance.
- `docs/design/*.md`: dependency, layout, shift, action, and AD conventions.
- `.github/workflows/ci.yml`: fmt, Clippy, and tests.
